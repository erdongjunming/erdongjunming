## 核心测试示例

```python
def test_copy_is_source_to_target():
    from world_model_lab.env.runtime import RegisterRuntime
    initial = {"env_version": "reg4/1.0.0", "registers": [1, 2, 3, 4]}
    result = RegisterRuntime().transition(initial, {"op": "COPY", "source": 0, "target": 3}, ["COPY"])
    assert result["after"]["registers"] == [1, 2, 3, 1]
    assert initial["registers"] == [1, 2, 3, 4]
    result["after"]["registers"][0] = 8
    assert result["before"]["registers"] == [1, 2, 3, 4]
```

测试矩阵至少覆盖每种合法动作的边界索引与数值。相同 State/action/allowed_ops 重复 100 次结果相同；不能仅调用同一实现计算“预期值”。
