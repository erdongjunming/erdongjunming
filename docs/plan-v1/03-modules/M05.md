# M05：任务仓库、冻结任务集与防泄漏

前置：M02/M03。门槛：G2。权重：2。输入：环境与验证器端口；输出：TaskRepositoryPort、任务清单、数据摘要与生成资料。

## 文件与接口

拥有 `src/world_model_lab/tasks/{__init__,repository,generator}.py`、`tasks/`、`tests/tasks/`。入口 `JsonTaskRepository(root_dir: str)` 实现 load/list_ids/dataset_digest；load 深复制，list_ids 词典序排序。

公开任务 `tasks/public/smoke.jsonl` 与 `dev.jsonl`；答案/生成路径 `tasks/private/generation.jsonl`；清单 `tasks/manifest.json`。模型只能读取传入 Task，不能访问 private。v1 是可信研究脚本边界，进程内规则并不阻止恶意 Python 导入；模型不执行 Python，所以不要把文件分区宣传成安全隔离。

## 制作步骤

- [ ] 固定 golden swap-demo 任务，验证仓库类型与 Task 跨字段检查。
- [ ] 固定随机种子 42，生成 30 个 smoke：六种 family 各 5；100 个 dev：set15/add20/copy15/swap15/combined15/restricted20。task_id、内容重复分别检查；smoke 与 dev 内容不重合。
- [ ] 按 initial/goal/allowed_ops 的规范化内容去重，不用不同 task_id/family/seed 冒充不同题目。smoke 必须包括 swap-demo-001；其 restricted5 与 dev 的 restricted20 使用不同的候选组合。生成候选最多尝试 10,000 次，数量不足时明确失败，不无限重试。
- [ ] 每项任务从合法初始态执行一条不超过 20 步的生成轨迹形成可达目标，用独立 Verifier 检查；保留轨迹但不公开给 DecisionPort。
- [ ] restricted20 使用全零初值、仅 ADD、一个目标索引达到 ±5/±6/±7/±8、其他三项 preserve，按索引与目标词典序选 20 个；任务最短步数 3 或 4，可用数值下界和 bounded search 双重核验。
- [ ] 冻结公开 JSONL 的逐行 canonical JSON，每行一个 Task；dataset_digest 对整个规范化内容（末尾带换行）哈希。仓库 root 只代表一个集合，不能混合 smoke/dev 后仍用单集合摘要。
- [ ] manifest 记录 seed、生成器提交、Schema/env 版本、每种 family 数量、文件摘要、难度标签。模型请求中不暴露最短解。

## 核心验收

```python
def test_task_loaded_as_copy(repository):
    task_id = repository.list_ids()[0]
    first = repository.load(task_id)
    first["initial"]["registers"][0] = 8
    second = repository.load(task_id)
    assert first is not second
    assert repository.dataset_digest().startswith("sha256:")
```

另用明确初始值检查修改副本未影响下一次加载。重新生成两次公开文件字节及 digest 相同；restricted 目标没有通过 SET/SWAP 提前解决的权限。把答案轨迹字段塞入 Task 应被公共 Schema 拒绝。
