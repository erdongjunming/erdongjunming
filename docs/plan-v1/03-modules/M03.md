# M03：独立目标验证与转移审计

前置：M01。门槛：G1。权重：2。输入：Task/State、action/allowed_ops/TransitionResult；输出：VerificationResult、AuditResult。

## 文件与接口

拥有 `src/world_model_lab/verification/{__init__,verifier}.py`、`tests/verification/`。入口 `IndependentVerifier()`；实现 VerifierPort 的两个方法。

只能使用公共结构验证/哈希工具，不导入 M02 的转移实现，不调用 Runtime 来生成预期输出。

## 制作步骤

- [ ] 使用人工目标与 golden V01-V03 写独立测试；先固定 preserve 是最终状态相对 Task.initial。
- [ ] check 按目标索引和 preserve 分别检查，violations 按 code 再按 index 排序，success 只在零 violations 时为 true。
- [ ] audit_transition 根据动作定义独立检查：accepted/error 一致性、禁止动作、剪裁结果、未涉及寄存器不变、输入/输出合法。
- [ ] 写错误注入测试：COPY 方向反转、ADD 9 未截断、SET 多改一个寄存器、非法动作修改状态、accepted=false 但 error=null。
- [ ] 检查目标冲突、类型坏输入使用 PortError；不把坏 Task 当成普通任务失败。
- [ ] 阅读 M02 已合并实现进行独立复核，测试仍保留单独公式与人工断言。

## 核心测试示例

```python
def test_target_met_but_preserve_broken(task):
    from world_model_lab.verification.verifier import IndependentVerifier
    result = IndependentVerifier().check(task, {"env_version": "reg4/1.0.0", "registers": [2, 1, 0, 4]})
    assert result["success"] is False
    assert result["violations"] == [{"code": "preserve_violation", "index": 2, "expected": 3, "actual": 0}]
```

task fixture 在本模块测试 helper 中从 golden.task 深复制。此处变量代表该固定任务，不由 planner 提供目标。
