# M10：命令行、组合根与可交付版本

前置：M07/M09；M08 的接入在 G3 更新。门槛：G2/G3。权重：2。输入：用户命令与本地配置；输出：演示、运行证据和报告路径。

## 文件与接口

拥有 `src/world_model_lab/cli/{__init__,main,assembly}.py`、`src/world_model_lab/__main__.py`、`configs/local/`、`tests/cli/`、`docs/user/`。使用 argparse；M00 配置 console script，如需要。

assembly 是唯一生产组合根：创建 Runtime、Verifier、SQLiteStore、planner/adapter factory、RunOrchestrator、EvaluationRunner。其余模块不互相创建具体实现。

## 命令界面冻结

```powershell
python -m world_model_lab demo --output runs/demo
python -m world_model_lab snapshot-demo --output runs/snapshot-demo
python -m world_model_lab run --task-set tasks/public/smoke.jsonl --task-id swap-demo-001 --planner heuristic --output runs/one
python -m world_model_lab evaluate --task-set tasks/public/dev.jsonl --planners random,heuristic,exact_search --seed 42 --output runs/dev42
python -m world_model_lab replay --export runs/demo/run-export.json
python -m world_model_lab run --task-set tasks/public/smoke.jsonl --task-id swap-demo-001 --planner llm --provider-config configs/providers/provider-a.json --output runs/live-a
```

`demo` 内嵌使用 golden.task，不依赖 smoke 文件里必有该 ID。M05 应把 swap-demo-001 纳入 smoke 的 5 个 swap 任务，使 run 示例可直接执行。M00/M01 提供冻结 golden 资源。

## 制作步骤

- [ ] 参数解析与配置验证；禁止未指定 provider-config 就执行 planner=llm；离线模式不得自动下载模型或调用外网。
- [ ] 输出目录已存在且含运行数据时拒绝，用户需选择新目录；不覆盖报告或旧 DB。文件名仅由程序生成，任务 ID 不拼接为任意路径。
- [ ] demo 执行 swap-demo、输出初态/实际动作/最终独立验证/真实查询计数/完整导出路径。
- [ ] snapshot-demo 显示 parent/child 不同状态和共享预算，独立验证恢复语义。
- [ ] evaluate 接 M09；任何单 run 成功/失败由 report 表达，批处理技术完成可 exit 0，但存在审计/协议/存储故障 exit 2。run 成功 exit 0，未达成目标 exit 1，配置/技术错误 exit 2；Ctrl+C exit 130。
- [ ] 把公共 CLI 示例运行一遍，记录版本、输出路径、测试结果；完善“预测与事实区别”“支持的恢复范围”“真实兼容状态”等使用说明。
- [ ] G2 交付离线标签；G3 增补真实后端配置样例与各自证据。模型名称参数来自实际可访问后端，不在程序默认值中猜测。

## 验收

CLI 用 subprocess 执行，核查退出码、文件存在及 Schema，不只调内部函数。无 key 的机器能跑 demo/evaluate/replay；live 命令缺 key 明确退出 2。中文和空格路径测试不截断、不乱码。
