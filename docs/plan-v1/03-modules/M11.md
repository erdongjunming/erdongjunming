输入：版本化 State/Action 转移数据；输出：WorldModelPort、预测评测与公平规划报告。预测器不接管事实和目标验收。

## 文件与接口

拥有 `src/world_model_lab/world_models/{__init__,identity,tabular,adapter}.py`、`research/`、`tests/world_models/`。身份预测与表格预测先使用 CPU/标准库。神经网络依赖只能在 `research/.venv` 中安装并由 M00 记录，保持基础平台可安装。

`IdentityWorldModel()`、`TabularWorldModel(artifact_path: str)` 实现 WorldModelPort；未知状态-动作条目返回 abstain，不能退回真实 Runtime 并冒充学习预测。后续 LearnedPlanner 通过 DecisionFactoryPort 接收计量预测器，不直接调用 Store。

## 制作步骤

- [ ] R1 数据设计：收集多条合法轨迹，每条最多 20 步，目标总计至少 10,000 个合法转移；每条保留 trajectory_id、state/action/next_state、策略、版本、来源、seed。拒绝动作另建诊断集。
- [ ] 按轨迹分组切分 70%/15%/15%，固定 seed=42；相同 state/action 组合跨集合的条目移到训练或隔离区，不能简单随机行切分。保留多步未见组合、边界和常见组；记录每组实际样本数。
- [ ] R2 先比较下一状态不变、表格缓存、精确规则、简单统计预测；完整状态准确率与每寄存器准确率分开，多步 rollout 报 1/3/5/10 步全状态匹配。
- [ ] R3 表格未知项 abstain；报告 coverage 与错误率，不把拒绝样本从分母消失。只有验证集上的预测改善值得继续，才申请小网络实验；锁定训练数据和环境。
- [ ] R4 比较无预测、精确搜索、缓存搜索、学习辅助规划，动作预算和总精确+预测查询预算一致。每轮只执行一个真实动作；身份预测错误不能让 run 成功。
- [ ] R5 对成功率用配对任务比较，对时延固定机器/线程/顺序并报告中位数/P95；至少三组固定种子，单独报告训练成本与推理成本。只在冻结 dev 调参，保留研究 test 不调参。
- [ ] 提交负结果和失败轨迹；结果未优于简单方法时保留工程平台，不扩大模型来规避结论。
