# M01：公共类型、端口、数据验证与固定样例

前置：M00。门槛：G0。权重：3。输入：01-contract、参考 Schema/.pyi/golden；输出：所有模块共同依赖的可运行 contracts。

## 文件与接口

拥有 `contracts/v1/`、`src/world_model_lab/contracts/{__init__,types,ports,validation,canonical}.py`、`tests/contracts/`。将参考 types.pyi/ports.pyi 转为 `.py`；保留规范 `.pyi` 作为契约摘要来源。

固定公共辅助接口：

```python
def canonical_json(value: JsonValue) -> str: ...
def state_id(state: State) -> str: ...
def validate_object(type_name: str, value: object) -> None: ...
def validate_task(task: Task) -> None: ...
def validate_decision(decision: Decision) -> None: ...
def validate_prediction(prediction: Prediction) -> None: ...
```

结构验证失败使用 PortError(schema_mismatch)，决策/预测违反跨字段规则也同样拒绝。Runtime 的 action 错误分类由 M02 按 contract 的顺序产生，不直接把所有动作错误变成 schema_mismatch。

## 制作步骤

- [ ] 保存固定契约，运行 Draft202012Validator.check_schema；解析两个 `.pyi`，核对 TypedDict 字段、Literal、Protocol 的方法和返回类型。
- [ ] 用 jsonschema 验证 schema_samples 与 golden.task。补充 Task、Observation、DecisionRequest、StepReceipt、RunExport、RunSummary 的完整正反样例，并由独立复核人检查；首批是计划样例，不是实际执行证据。
- [ ] 写 canonical_json/state_id；拒绝重复键、bool-as-int、非有限浮点数。JSON Schema 默认允许 1.0 满足 integer，需要用 jsonschema TypeChecker 将 integer 重定义为 `type(value) is int`，与 Python/动作规则一致。通用边界 JSON 最大 1MiB、嵌套最多 32 层；超限拒绝。传输原始响应另限 256KiB，不套用日志导出的批量流大小。
