# M08：模型适配、厂商协议转换与兼容验证

前置：M01；真实闭环等 G2。门槛：G3。权重：3。输入：DecisionRequest；输出：Decision 与 ProviderUsage。消费者：M07。

## 文件与接口

拥有 `src/world_model_lab/adapters/{__init__,scripted,chat_completions,messages,transport,factories}.py`、`tests/adapters/`、`configs/providers/`。

三个 DecisionPort：`ScriptedAdapter(decisions: list[Decision])`、`ChatCompletionsAdapter(config, transport)`、`MessagesAdapter(config, transport)`。两个真实类必须符合相同 decide/usage 方法。config 是该模块内部经验证的配置，不是公共协议扩展点。

factory 实现 `DecisionFactoryPort.build(config: RunConfig, runtime: RuntimePort, world_model: WorldModelPort | None)`；用 config 构造绑定本 run 的计量 transport、超时和金额限制，不使用 runtime 执行模型动作。

内部 provider 配置字段固定：provider_id、model、base_url、api_key_env、response_mode(tool/json)、max_output_tokens、pricing(input_per_million/output_per_million/currency 或 null)、transport_profile。base_url 默认只接受 HTTPS，允许明确配置的 loopback HTTP 本地后端；禁止从模型响应修改地址。原始响应只保留脱敏的受限摘要和必要证据。

内部 transport 固定 `send(payload: dict, timeout_ms: int) -> dict`，生产支持硬超时、受限响应体与禁用跨域重定向；测试用 FakeTransport 注入响应、异常和用量。真实适配器 config 的字段清单写入本模块 README/测试，不让其他模块依赖。

## 制作步骤

- [ ] 制作 ScriptedAdapter；明确其不发网络请求，usage 返回零调用且零 API tokens；每轮返回 request_id 对应当前请求。
- [ ] 构造中立系统指令与状态/目标/合法动作/预算；单个工具只生成候选动作集合。模型不得自填 Command 的权限字段；每次发请求前剔除私有路径与秘密。
- [ ] ChatCompletionsAdapter 把目标后端的工具调用/严格 JSON 响应转换为 Candidate；MessagesAdapter 独立处理 message/content/tool-use 协议。各自保留厂商字段在 adapter 内，不通过 Runtime 识别。
- [ ] 实施前核对所选真实 provider 的当前官方文档、模型能力和许可；本计划不假设所有兼容接口都支持同一工具字段。工具不可用时可走受限 JSON 文本模式，能力开关必须记录。
- [ ] 拒绝未知工具、额外 shell/网络权限、多工具副作用、无效动作、超大响应、错误 JSON。错误内容作为 provider_protocol，不执行文本。
- [ ] 处理限流/超时/认证/余额错误，落实最多两次 HTTP 尝试和预算预检。Retry-After 有界且不超过 run 剩余时间；日志脱敏。
- [ ] 写每个后端假响应契约套件，报告用量缺失为 null；不能从文本长度臆测官方计费 tokens。
- [ ] G2 后用两种协议真实运行，具体品牌由已有可访问服务决定：一种 chat-completions 工具/JSON 风格，一种 messages/tool-use 风格。各至少 10 个有效调用，保存脱敏证据、provider/model/config 与时延。

## 具体测试

A08-1：fake 返回一个合法 SWAP → Decision 通过公共验证，并只含动作候选。

A08-2：fake 输出“任务已完成”但无候选 → provider_protocol 或 stop；M07 仍需独立核验，不能直接 success。

A08-3：429 后成功 → 两次 provider_calls；未知用量合计仍 null。

A08-4：认证/余额失败 → 一次调用，不重试；超时后明确保留未知计费情况。

A08-5：异常字符串包含示例密钥 → 输出报告/日志不包含该值；未知 tool run_shell → provider_protocol。
